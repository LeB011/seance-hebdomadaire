MISE À JOUR V4.1 — Base stable + correctif collaborateurs + thème clair premium

À faire sur GitHub : remplacer les fichiers par ceux du ZIP puis laisser Vercel redéployer.

Important : Supabase n'a pas besoin d'être recréé. Si tu n'as pas encore lancé supabase-schema.sql de la V4, lance-le une fois dans Supabase SQL Editor.

Nouveautés de la V4 / V4.1 :
- Déconnexion automatique après 1 heure d'inactivité.
- Popup d'avertissement avant déconnexion avec bouton “Rester connecté”.
- Verrouillage rapide de session.
- Compte admin principal admin@admin.ch.
- Panneau admin avec utilisateurs, rôle, statut en ligne/hors ligne et dernière activité.
- Présence utilisateur avec mise à jour automatique.
- Historique d'activité / logs.
- Nouveau système de tâches évolutives : À faire, En cours, En attente, Partiellement fait, À relancer, Urgent, Terminé.
- Progression de tâche en pourcentage.
- Historique d'évolution par tâche.
- Date de relance.
- Dashboard plus vivant avec tâches urgentes, tâches en retard, profils urgents, collaborateurs actifs et collaborateurs urgents.
- Recherche globale.
- Notifications internes navigateur.
- Statistiques améliorées.
- Correctif collaborateurs : bouton “Ajouter collaborateur” fonctionnel, formulaire prénom/nom/domaine/disponibilités/urgence/statut/téléphone/email/notes.
- Filtre et recherche dans les collaborateurs.
- Collaborateurs sauvegardés sans nouvelle table Supabase, via une note système cachée.
- Nouveau thème clair premium : fond blanc classe, cartes blanches, sidebar claire, boutons modernes, contrastes améliorés.
