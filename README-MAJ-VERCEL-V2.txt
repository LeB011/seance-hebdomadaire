VERSION MAJ VERCEL V2 - 12.05.2026

Ce ZIP contient la version complète prête à remplacer sur GitHub.

Améliorations ajoutées :
- Dashboard premium renforcé avec notes, tâches et collaborateurs.
- Sidebar déjà organisée en catégories.
- Recherche globale notes + tâches + collaborateurs.
- Statistiques enrichies avec collaborateurs par domaine.
- Page Collaborateurs refaite :
  - prénom
  - nom
  - domaine
  - début de disponibilité
  - fin de disponibilité
  - urgent oui/non
  - statut
  - téléphone
  - email
  - notes
- Filtres collaborateurs : urgents, fin dépassée, début bientôt, actifs, inactifs.
- Sauvegarde collaborateurs sans nouvelle table Supabase : stockage dans une note système cachée.
- Notes système masquées des Notes, Archives, Recherche et Exports.
- Compatible GitHub + Vercel.

Important :
- Ne supprime pas config.js.
- Tu peux remplacer les fichiers sur GitHub avec ce ZIP.
- Pas besoin de refaire Supabase pour cette mise à jour.
- Si Vercel ne redéploie pas automatiquement : va dans Vercel > Deployments > Redeploy.
